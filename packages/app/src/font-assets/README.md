These WOFF2 files are the Latin subsets from Fontsource 5.3.0. They are
bundled so `next/font/local` builds without fetching Google Fonts.

- `ibm-plex-mono-latin-*-normal.woff2`: `@fontsource/ibm-plex-mono`
  (`OFL-IBM-Plex-Mono.txt`)
- `inter-latin-wght-normal.woff2`: `@fontsource-variable/inter`
  (`OFL-Inter.txt`)
- `roboto-latin-wght-normal.woff2`: `@fontsource-variable/roboto`
  (`OFL-Roboto.txt`)
- `roboto-mono-latin-wght-normal.woff2`: `@fontsource-variable/roboto-mono`
  (`OFL-Roboto-Mono.txt`)
